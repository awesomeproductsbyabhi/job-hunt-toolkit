# Interview debrief

Run within two hours of the interview, while memory is fresh. Load the playbook's debrief template and learnings log, the story bank and the company's prep doc.

## Capture
Walk through the template one item at a time and accept rough notes: facts (company, role, round, date, duration, interviewer, format); every question in order, in the user's words; for each, the gist of the answer, its length and the interviewer's reaction; where the user stumbled; what landed; signals about the role; surprises the prep doc missed; anything to double-check; next steps and timing; a self-score from 1 to 5. Do not coach during capture.

## Then, in order
1. Add one row per question to the learnings log (newest first) with the fix and where it will be moved.
2. Check every number the user was unsure about against the numbers sheet and the career notes.
3. Propose, for the user's confirmation, updates to story cards, standard answers, the prep doc, and any new playbook rule if a mistake has repeated. Never save a change without confirmation.
4. Update the pipeline row: stage, next step, next date, and a dated note. Never delete rows.
5. Write the next round's prep page around what this round exposed.
6. Draft a short same-day follow-up with one specific point from the conversation, for the user to send. For a rejection, draft a one-line feedback request.

## Rules
Only claims that trace to the career notes. Be honest about weak answers without softening the facts, and keep the tone steady. Create nothing outside the session; the user sends all messages.
